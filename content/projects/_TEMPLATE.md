# HOW TO ADD A PROJECT
#
# 1. Duplicate this file in the same folder.
# 2. Rename it, starting with a number. The number decides where it appears in
#    the sidebar, and the rest becomes the web address. For example:
#       07-my-new-script.md   ->   /work/my-new-script
# 3. Fill in the settings below, then write the page under the second --- line.
# 4. Delete any line you do not need. Only "title" and "cover" are required.
#
# Keep the quotes around every value.

title: "A Blacksmith's Purpose"

# The main photo. Put the image file in the "public/images" folder, then write
# its name here after /images/.
cover: "/images/your-image.jpg"

# ---- Everything below this line is optional. Delete what you do not want. ----

# A short description of the image, read aloud by screen readers.
coverAlt: "Describe what is in the image"

# A shorter name for the sidebar, if the full title is long.
navLabel: "Short Title"

# The small line above the title, and the year.
kicker: "Feature screenplay"
year: "2026"

# One sentence describing the project. Shown on the home and Work pages.
logline: "One sentence that makes someone want to read the rest."

# A wider image for the top of the project page. If you leave this out, the
# cover image is used instead.
lead: "/images/your-wide-image.jpg"
leadAlt: "Describe what is in the image"
leadCaption: "A caption under the image."

# The line under the title on the Work page.
format: "Feature screenplay · 100 pages"

# The small table under the main image. Add or remove rows freely.
facts:
  "Format": "Feature screenplay"
  "Length": "100 pages"
  "Genre": "Drama"
  "Status": "First draft"

## A heading

Write normally. A blank line starts a new paragraph.

You can make text **bold** or *italic*, and add [a link](https://example.com).

![Describe the image](/images/another-image.jpg "A caption under the image.")

## Another heading

Put two images on the same line, with nothing between them, to show them side
by side:

![First image](/images/one.jpg "Left caption.")![Second image](/images/two.jpg "Right caption.")
